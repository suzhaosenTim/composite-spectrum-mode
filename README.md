# Composite-spectrum-mode
Repository used for running experiments in ''A unified boundary integral framework for spectral analysis of operators in composite materials.''
In short, it mainly computes the spectrum and associated eigenmodes of the volume operator for the analytic continuation method of two-phase composite materials via the boundary integral method.
Additionally, it computes the electric potentials and fields for perfectly conducting inclusions. 

# Dependecies
The main implementations here require ChunkIE: a MATLAB integral equation toolbox. For detailed instructions of this package, please refer to: https://github.com/fastalgorithms/chunkie.

# Usage
Make sure the helpers/ folder is added to the path.
